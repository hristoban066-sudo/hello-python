# Калкулатор за средна цена на акция (за начинаещи)

Това е много проста уеб страница (`index.html`), която смята средната цена на акция по въведени покупки.

## Как да я ползваш

1. Отвори файла `index.html` в браузър (Chrome, Edge, Firefox).
2. На първия ред въведи:
   - **Брой акции** (например `10`)
   - **Цена** (например `100`)
3. Ако имаш още покупки, натисни бутона **„Добави“** и попълни нов ред.
4. Натисни **„Изчисли средна цена“**.
5. Ще видиш:
   - **Общо акции**
   - **Общо инвестирана сума**
   - **Средна цена на акция**

## Полезни съвети

- В полето за цена може да пишеш и с точка, и със запетая (например `100.5` или `100,5`).
- Ако има грешни данни (например празно поле или 0 акции), страницата ще покаже съобщение какво да поправиш.
