# Калкулатор за средна цена на акция

`index.html` е проста страница за начинаещи.

## Кратки инструкции

1. Отвори `index.html` в браузър.
2. Въведи **Брой акции** и **Цена** за покупката.
3. За още покупки натисни **„Добави“**.
4. Натисни **„Изчисли средна цена“**.
5. Резултатът показва:
   - **Общо акции**
   - **Общо инвестирана сума**
   - **Средна цена на акция**

## Подсказка

- Ако въведеш грешни данни, ще видиш съобщение какво да поправиш.
